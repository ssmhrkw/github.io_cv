## 2. 16 Hz で全体が小さくなる問題

### 2.1 再現（元ファイル、実 Chromium、44.1 kHz、未校正）

`tests/repro-orig.mjs` の結果。

| 帯域 | 全セル共通の減衰 | LH-80 衝撃音ピーク | 暗騒音 40 dB(A) 実効値 | 暗騒音 20 dB(A) 実効値 |
|---|---|---|---|---|
| 63 Hz〜1 kHz | −14.0 dB | −16.1 dBFS | −72.5 dBFS | −92.5 dBFS |
| ＋31.5 Hz | −21.0 dB | −15.8 dBFS | −79.6 dBFS | −99.6 dBFS |
| ＋16 Hz | **−40.4 dB** | −15.6 dBFS | **−99.0 dBFS** | **−119.0 dBFS** |

16 Hz を含めると、暗騒音 40 dB(A) が 16 bit の量子化雑音（約 −96 dBFS）より下になる。これが「暗騒音まで聞こえない」の正体である。

### 2.2 段階ごとの内訳（元ファイル、16 Hz 込み）

| 段階 | 値 | 備考 |
|---|---|---|
| モデル上の目標 | 16 Hz 帯 L<sub>Fmax</sub> = 103.4 dB（LH-50）、133.4 dB（LH-80） | 逆 A 外挿。500 Hz 帯より 53 dB 大きい |
| 校正係数 | K = 118 dB 固定（未校正時） | LH-80 のピークは +24.9 dBFS 相当 |
| 重なりの仮定 | ピーク × 3（+9.5 dB） | 実際には T = 0.5 s の波形長 1.25 s は打撃間隔より短く、重ならない |
| 暗騒音 70 dB(A) のピーク | −16.5 dBFS を加算 | |
| 目標上限 | −6 dBFS | |
| **共通ゲイン** | **−40.4 dB** | 「最悪セル」に合わせて全セルに適用。帯域を変えるたびに黙って変わる |
| アプリ内の音量 | なし | |
| 出力 | LH-50 ピーク −45.5 dBFS、暗騒音 30 dB(A) −109 dBFS | |

原因は3つ重なっている。(1) 全セル中の最悪条件（LH-80 × 3打 ＋ 暗騒音70）を共通の上限にしている、(2) 重なりを実波形でなく「ピーク3倍」と仮定している、(3) 上限が −6 dBFS と低い。帯域を変えると共通ゲインが変わるので、帯域の有無を聴き比べることもできなかった。

## 3. 音量設計

```
デジタル信号 = モデル音圧 ÷ (20 µPa × 10^(K/20)) × 出力レベル
```

- **K は固定**。未校正時 126 dB（出力レベル 0 dB でモデル上 126 dB のピークが 0 dBFS）。校正時は帯域ごとの実測値。セル・帯域・音源を変えても変わらない。
- **共有ゲイン（マスター）はユーザーの「出力レベル」だけ**（−40〜+20 dB、5 dB 刻み、全条件共通、画面下に常時表示）。セル切替では触らない。旧音源が残っている間に共有ゲインが上がる経路は存在しない。
- **自動正規化なし**。上限 −1 dBFS を超える組み合わせは再生せず、斜線のセルに「再生できる出力レベル」を数字で出す。押すと「出力レベルを −20 dB に下げて再生（全条件が 20 dB 小さくなります）」というボタンが出て、押したときだけ下がる。
- **重なりは実波形**。3回（1 s 間隔）・連続（1.8 s 間隔）それぞれ、ずらして重ねた波形のピークを計算する。
- **校正信号は出力レベルを通らない**（常に −20 dBFS、0.3 s でフェードイン）。
- 低域の削除・圧縮・帯域別の増減はしていない。描画した出力を音圧に戻して 1/1 オクターブ分析すると、16 Hz 帯を含め全帯域が目標 ±0.01 dB（試験 02）。
- 「試聴モード（セルごとにゲイン調整）」は廃止した。同じ目的は出力レベルで足り、モードによって比較の意味が変わる状態をなくした。

### dB の区別

| 表記 | 意味 | 画面での場所 |
|---|---|---|
| モデル上の dB | 計算目標（dB re 20 µPa） | グラフ・帯域表・セルの行列見出し |
| dBFS | デジタル出力（ピークまたは実効値） | 「選択中の条件」の数値欄 |
| dB SPL | 校正済み かつ 出力レベル 0 dB のときだけモデル dB と対応 | 「音量の基準」欄に状態を表示 |

## 4. 16 Hz を含めるときの使い方（短い説明）

1. 「16 Hz」にチェックを入れても、音量は変わらない。63〜500 Hz の成分と暗騒音はそのまま、16 Hz 成分が足されるだけ。
2. 出力レベル 0 dB では LH-60 まで再生できる。LH-65 以上は斜線になる。
3. LH-80 まで比べたいときは出力レベルを −20 dB にする。全条件が 20 dB 小さくなり、5 dB 差と衝撃音／暗騒音の比は保たれる。
4. そのとき暗騒音 20 dB(A) は −106.6 dBFS、40 dB(A) は −86.6 dBFS になる。−90 dBFS を下回ると画面に「ほぼ無音」と数値つきで出る。

**同時には満たせないこと**：16 Hz 込みの LH-80（ピーク +17.0 dBFS 相当）と暗騒音 20 dB(A)（実効値 −86.6 dBFS）の差は 103.6 dB で、16 bit（96 dB）に収まらない。24 bit 機器でも実用上の限界に近い。スペクトルを保つ限り、「LH-80 まで」と「静かな暗騒音が聞こえる」は両立しない。実用上は、(a) 16 Hz 込みは LH-60 以下で比べる、(b) 高い等級は暗騒音 40 dB(A) 以上の列で比べる、のどちらかになる。16／31.5 Hz を再生できない機器では聞こえる部分が小さいままなので、端末の音量は上げないこと（画面にも記載）。

## 6. TL は外挿する／しないのどちらが分かりやすいか

結論：**既定は外挿しない（125 Hz〜2 kHz）**。外挿は選択式で残した。

- 遮音後の音の大きさは、減衰が小さい低い側の帯域でほぼ決まる。外挿すると、良いヘッドホンでは 63 Hz 以下（等級 50 で 27.5／20／12.5 dB という仮定値）が聞こえ方を支配する。聴いているのは等級ではなく外挿の仮定になる。
- 小型スピーカーでは外挿した低域が出ないので、機器によって印象が大きく変わる。定義範囲だけなら機器差が小さい。
- 実際の壁の低域は共鳴透過などで曲線の延長から大きく外れる。外挿値で「この等級の壁はこう聞こえる」と受け取られるのは避けたい。
- 欠点は、原音も 125 Hz〜2 kHz に制限されるので、音楽では低音と高域が欠けて聞こえること。会話・テレビ音声では違和感が小さい。音楽の低音の漏れを確かめたい場合は「63 Hz〜8 kHz（参考外挿）」を選ぶ。その場合は点線・「（外挿）」表示・注記が出る。
- 高域（2 kHz 超）の水平延長は遮音後の大きさにほとんど影響しないので、原音の自然さを優先するなら「125 Hz〜4 kHz」が中間案になる。

|---|---|---|---|

| 直線 | 10 ms | −82 dB | −31 dB |

| **二乗余弦** | **10 ms** | **−112 dB** | **−61 dB** |
| 二乗余弦 | 20 ms | −125 dB | −74 dB |

10 ms の二乗余弦を採用した。遮音後の音に対しても 60 dB 以上下で、これより短くする利点（5 ms 早い）より余裕を取った。位相・相関について：全条件は同じ信号をゼロ位相で整形したもので完全に相関している。相補的な重み（足して 1）なら、切替中の出力は周波数ごとに一方からもう一方へ単調に移る。実波形でも、切替中の全サンプルが max(|旧|, |新|) 以下、理想の相補クロスフェードとの誤差 −97 dB、遮音条件どうしでは 2 つのレベルの間から外れない（誤差 10⁻¹¹）ことを確認した。等電力型（足して 1 を超える重み）は相関信号では最大 +3 dB 膨らむので使っていない。

切替は「前の合成音 ×(1−w) ＋ 新しい音 × w」を1段ずつ積み重ねる構造にした。各ゲインは1回だけ自動変化し、途中で打ち切らない。そのため切替が重なっても待ち行列ができず、出力は常に関係する信号の凸結合になる。停止はその全体にもう1段のフェードを掛け、まだ始まっていない切替は破棄する。

原音の急な大音量について。原音への切替は「実際の差の分だけ一気に大きくなる」ことが比較の中身なので、瞬時にした。保護は3つ残している。(1) 再生開始時に原音を選んでいる場合だけ 0.2 s で立ち上げる、(2) 「原音だけ 10／20／30 dB 下げる」設定（使うと聞こえる差がその分小さくなることを画面に表示）、(3) 全条件共通の音量。遮音後だけの自動正規化はしていない。

### 13.2 16 Hz（依頼2）

設計は3章のまま（固定の換算、明示的な出力レベル、自動正規化なし）。T の初期値を 0.7 s にしても数値はほぼ同じで、16 Hz 込みは出力レベル 0 dB で LH-60 まで、全セルには −20 dB、そのとき暗騒音 20 dB(A) は −106.6 dBFS。LH-80（16 Hz 込み）のピークと暗騒音 20 dB(A) の実効値の差は約 103 dB で、16 bit には収まらない。

「音量ボタンで後から上げ下げすればよいか」について。アプリ内の出力レベルを下げるのは有効（クリップ前の信号を下げる）。逆に、デジタル出力がクリップした後で端末側の音量を下げても歪みは戻らない。このため上限を超える組み合わせは再生自体をしない。再生できない・小さい・機器が出せない、の区別：(a) 上限超過は斜線セルで再生不可、(b) 再生できるが小さい場合は dBFS を数値で表示し −90 dBFS 未満は「ほぼ無音」と表示、(c) 機器が 16／31.5 Hz を再生できるかは、このページからは判定できない（注意書きのみ）。

短い WAV＋16 Hz の帯域レベルずれは 12章の1（v2.0.1 で修正済み、試験 08）。

### 13.4 表の数値と L_A,Fmax（依頼4）

コードで確認した「数字」の意味と、v2.1.0 での表記。

| 場所 | 意味 | 計算 | 表記 |
|---|---|---|---|
| 表の斜線セル | そのセルを再生できる出力レベル（上限 −1 dBFS から逆算、5 dB 刻み） | 20 log₁₀(上限 ÷ セルのピーク上限) | 「−20」→「**≤−20**」 |
| 表のセル（チェック時） | 衝撃音の参考 L_A,Fmax − 暗騒音のモデル L_Aeq | 下の ① − 列の値 | 「+12」→「**Δ12**」 |
| 指定値モードの行名 | 入力値からの平行移動量 | 5 dB 刻み | 「+5」→「**+5 dB**」 |
| 画面下の出力レベル | 全条件共通のゲイン | — | 「+5 dB」（変更なし） |

衝撃音の作り方と L_A,Fmax：

- 帯域ごとに減衰正弦波の和を作り、**合成後の波形**を帯域フィルタ→F 特性（125 ms）→最大値で分析して、各帯域の L_Fmax が目標に一致するよう帯域ゲインを反復補正している。合わせているのは帯域別 L_Fmax だけ。
- ①「波形から求めた参考 L_A,Fmax」は、その**全帯域の合成波形に A 特性フィルタを掛け、F 特性の時間重み付け後に最大値を取った**値である。帯域ごとに A 補正を足してエネルギー合算したものではない。
- ②「帯域別 L_Fmax ＋ A 補正のエネルギー合算」を別の参考値として併記した。各帯域の最大が同時に起こると仮定した量で、① とは一致しない。実測した1条件（16 Hz 込み、LH-50、T＝0.7 s）では ① 51.4 dB、② 52.3 dB だった。ほかの条件での差は画面の「②−①」で確認できる。
- 帯域別最大値の時刻や波形が変われば ① は変わる。したがって ① は「基準曲線の値」ではなく「この波形の値」であり、画面でもそう書いている。
- ①② とも、出力レベル・暗騒音・連続打撃の重なり・校正を含まない。規格の測定条件を満たす値ではない。
- Δ は最大値（衝撃音）と時間平均（暗騒音）の比較なので、聞こえやすさの目安にとどまる（Δ が 0 でも衝撃音は聞こえる）。Δ の表示は既定でオフ。

各国の規格で全帯域 A 特性最大値と帯域別評価のどちらを使うかは、今回は調べていない（未確認事項）。

### 13.5 再生条件・暗騒音 WAV・再生中の編集（依頼5〜7）

- 連続の打撃間隔 1.9 s（8 打すべて 1.9000 s を波形で確認）、T の初期値 0.7 s（保存済みの値は引き継ぐ）。2 kHz の基準値は 61 dB（LH-65）のまま。
- **暗騒音の WAV**：2 秒以上、先頭 30 秒まで、全チャンネルの平均でモノラル化、再生側のサンプリング周波数へ変換。ループ長は 2 のべき乗サンプル（例：5 s の録音で 2.97 s、3 s の録音で 1.49 s）で、ループ末尾に続く部分を先頭へ最大 0.5 s でクロスフェードする。レベルは、選んだ暗騒音の帯域内の A 特性実効値（モデル L_Aeq）が列の値になるよう全体を一律に増減する。録音の dBFS は使わない。したがって合成ノイズとの比較は「同じモデル L_Aeq で、スペクトルが違う」比較として成立する。実際の音圧は校正がなければ決まらない。帯域内のエネルギーが全体の 0.01 % 未満の録音は、雑音だけを持ち上げることになるので合成ノイズへ戻す。録音は保存しない（開き直すと合成に戻る）。
- **再生中の編集**：基準値・オフセット・指定値・T・暗騒音の傾き／帯域／音源・追加帯域を変えると、入力が止まって 0.5 s 後に再計算し、再生を止めずに引き継ぐ。鳴っている打撃はそのまま鳴り終わり、次の打撃（同じ拍）から新しい音になる。暗騒音が変わる場合は同じ再生位置で 50 ms のクロスフェード。変更後の条件が上限を超える場合は止めて理由を表示する。停止中は鳴らさない。条件モードの切替、衝撃音の音源の切替、校正値の変更は従来どおり停止する。

### 13.8 残る制約・未検証

- 実際の聴取、騒音計での測定、Safari／Firefox／iOS／Android。特に `setValueCurveAtTime` と、同一タスク内でのノード接続の付け替えは Chromium でのみ確認した。
- 16 Hz 込みの高い等級と静かな暗騒音は同時に成立しない（13.2）。
- 暗騒音 WAV のループ長は 2 のべき乗に切り詰める（録音の半分近くを使わない場合がある）。継ぎ目のクロスフェードは、強い純音成分を持つ録音では一時的なレベル変化を生じうる（試験は雑音主体の録音で実施）。
- 再生中編集の再計算中（0.3〜1.5 s）は画面が一時的に固まる。音は予約済みの分で続く。
- TL の原音への切替は瞬時なので、遮音後に合わせて端末の音量を上げていると大きな音になる（画面に注意書きと「原音だけ下げる」設定）。
- 各国規格での L_A,Fmax の扱いの調査、JIS 本文との照合（9章）は未実施。
