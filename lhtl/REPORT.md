## 2. 16 Hz で全体が小さくなる問題

### 2.1 再現（元ファイル、実 Chromium、44.1 kHz、未校正）

`tests/repro-orig.mjs` の結果。

| 帯域 | 全セル共通の減衰 | LH-80 衝撃音ピーク | 暗騒音 40 dB(A) 実効値 | 暗騒音 20 dB(A) 実効値 |
|---|---|---|---|---|
| 63 Hz〜1 kHz | −14.0 dB | −16.1 dBFS | −72.5 dBFS | −92.5 dBFS |
| ＋31.5 Hz | −21.0 dB | −15.8 dBFS | −79.6 dBFS | −99.6 dBFS |
| ＋16 Hz | **−40.4 dB** | −15.6 dBFS | **−99.0 dBFS** | **−119.0 dBFS** |

16 Hz を含めると、暗騒音 40 dB(A) が 16 bit の量子化雑音（約 −96 dBFS）より下になる。これが「暗騒音まで聞こえない」の正体である。

### 2.2 段階ごとの内訳（元ファイル、16 Hz 込み）

| 段階 | 値 | 備考 |
|---|---|---|
| モデル上の目標 | 16 Hz 帯 L<sub>Fmax</sub> = 103.4 dB（LH-50）、133.4 dB（LH-80） | 逆 A 外挿。500 Hz 帯より 53 dB 大きい |
| 校正係数 | K = 118 dB 固定（未校正時） | LH-80 のピークは +24.9 dBFS 相当 |
| 重なりの仮定 | ピーク × 3（+9.5 dB） | 実際には T = 0.5 s の波形長 1.25 s は打撃間隔より短く、重ならない |
| 暗騒音 70 dB(A) のピーク | −16.5 dBFS を加算 | |
| 目標上限 | −6 dBFS | |
| **共通ゲイン** | **−40.4 dB** | 「最悪セル」に合わせて全セルに適用。帯域を変えるたびに黙って変わる |
| アプリ内の音量 | なし | |
| 出力 | LH-50 ピーク −45.5 dBFS、暗騒音 30 dB(A) −109 dBFS | |

原因は3つ重なっている。(1) 全セル中の最悪条件（LH-80 × 3打 ＋ 暗騒音70）を共通の上限にしている、(2) 重なりを実波形でなく「ピーク3倍」と仮定している、(3) 上限が −6 dBFS と低い。帯域を変えると共通ゲインが変わるので、帯域の有無を聴き比べることもできなかった。

## 3. 音量設計

```
デジタル信号 = モデル音圧 ÷ (20 µPa × 10^(K/20)) × 出力レベル
```

- **K は固定**。未校正時 126 dB（出力レベル 0 dB でモデル上 126 dB のピークが 0 dBFS）。校正時は帯域ごとの実測値。セル・帯域・音源を変えても変わらない。
- **共有ゲイン（マスター）はユーザーの「出力レベル」だけ**（−40〜+20 dB、5 dB 刻み、全条件共通、画面下に常時表示）。セル切替では触らない。旧音源が残っている間に共有ゲインが上がる経路は存在しない。
- **自動正規化なし**。上限 −1 dBFS を超える組み合わせは再生せず、斜線のセルに「再生できる出力レベル」を数字で出す。押すと「出力レベルを −20 dB に下げて再生（全条件が 20 dB 小さくなります）」というボタンが出て、押したときだけ下がる。
- **重なりは実波形**。3回（1 s 間隔）・連続（1.8 s 間隔）それぞれ、ずらして重ねた波形のピークを計算する。
- **校正信号は出力レベルを通らない**（常に −20 dBFS、0.3 s でフェードイン）。
- 低域の削除・圧縮・帯域別の増減はしていない。描画した出力を音圧に戻して 1/1 オクターブ分析すると、16 Hz 帯を含め全帯域が目標 ±0.01 dB（試験 02）。
- 「試聴モード（セルごとにゲイン調整）」は廃止した。同じ目的は出力レベルで足り、モードによって比較の意味が変わる状態をなくした。

### dB の区別

| 表記 | 意味 | 画面での場所 |
|---|---|---|
| モデル上の dB | 計算目標（dB re 20 µPa） | グラフ・帯域表・セルの行列見出し |
| dBFS | デジタル出力（ピークまたは実効値） | 「選択中の条件」の数値欄 |
| dB SPL | 校正済み かつ 出力レベル 0 dB のときだけモデル dB と対応 | 「音量の基準」欄に状態を表示 |

## 4. 16 Hz を含めるときの使い方（短い説明）

1. 「16 Hz」にチェックを入れても、音量は変わらない。63〜500 Hz の成分と暗騒音はそのまま、16 Hz 成分が足されるだけ。
2. 出力レベル 0 dB では LH-60 まで再生できる。LH-65 以上は斜線になる。
3. LH-80 まで比べたいときは出力レベルを −20 dB にする。全条件が 20 dB 小さくなり、5 dB 差と衝撃音／暗騒音の比は保たれる。
4. そのとき暗騒音 20 dB(A) は −106.6 dBFS、40 dB(A) は −86.6 dBFS になる。−90 dBFS を下回ると画面に「ほぼ無音」と数値つきで出る。

**同時には満たせないこと**：16 Hz 込みの LH-80（ピーク +17.0 dBFS 相当）と暗騒音 20 dB(A)（実効値 −86.6 dBFS）の差は 103.6 dB で、16 bit（96 dB）に収まらない。24 bit 機器でも実用上の限界に近い。スペクトルを保つ限り、「LH-80 まで」と「静かな暗騒音が聞こえる」は両立しない。実用上は、(a) 16 Hz 込みは LH-60 以下で比べる、(b) 高い等級は暗騒音 40 dB(A) 以上の列で比べる、のどちらかになる。16／31.5 Hz を再生できない機器では聞こえる部分が小さいままなので、端末の音量は上げないこと（画面にも記載）。

## 6. TL は外挿する／しないのどちらが分かりやすいか

結論：**既定は外挿しない（125 Hz〜2 kHz）**。外挿は選択式で残した。

- 遮音後の音の大きさは、減衰が小さい低い側の帯域でほぼ決まる。外挿すると、良いヘッドホンでは 63 Hz 以下（等級 50 で 27.5／20／12.5 dB という仮定値）が聞こえ方を支配する。聴いているのは等級ではなく外挿の仮定になる。
- 小型スピーカーでは外挿した低域が出ないので、機器によって印象が大きく変わる。定義範囲だけなら機器差が小さい。
- 実際の壁の低域は共鳴透過などで曲線の延長から大きく外れる。外挿値で「この等級の壁はこう聞こえる」と受け取られるのは避けたい。
- 欠点は、原音も 125 Hz〜2 kHz に制限されるので、音楽では低音と高域が欠けて聞こえること。会話・テレビ音声では違和感が小さい。音楽の低音の漏れを確かめたい場合は「63 Hz〜8 kHz（参考外挿）」を選ぶ。その場合は点線・「（外挿）」表示・注記が出る。
- 高域（2 kHz 超）の水平延長は遮音後の大きさにほとんど影響しないので、原音の自然さを優先するなら「125 Hz〜4 kHz」が中間案になる。

10 ms の二乗余弦を採用した。遮音後の音に対しても 60 dB 以上下で、これより短くする利点（5 ms 早い）より余裕を取った。位相・相関について：全条件は同じ信号をゼロ位相で整形したもので完全に相関している。相補的な重み（足して 1）なら、切替中の出力は周波数ごとに一方からもう一方へ単調に移る。実波形でも、切替中の全サンプルが max(|旧|, |新|) 以下、理想の相補クロスフェードとの誤差 −97 dB、遮音条件どうしでは 2 つのレベルの間から外れない（誤差 10⁻¹¹）ことを確認した。等電力型（足して 1 を超える重み）は相関信号では最大 +3 dB 膨らむので使っていない。

切替は「前の合成音 ×(1−w) ＋ 新しい音 × w」を1段ずつ積み重ねる構造にした。各ゲインは1回だけ自動変化し、途中で打ち切らない。そのため切替が重なっても待ち行列ができず、出力は常に関係する信号の凸結合になる。停止はその全体にもう1段のフェードを掛け、まだ始まっていない切替は破棄する。

原音の急な大音量について。原音への切替は「実際の差の分だけ一気に大きくなる」ことが比較の中身なので、瞬時にした。保護は3つ残している。(1) 再生開始時に原音を選んでいる場合だけ 0.2 s で立ち上げる、(2) 「原音だけ 10／20／30 dB 下げる」設定（使うと聞こえる差がその分小さくなることを画面に表示）、(3) 全条件共通の音量。遮音後だけの自動正規化はしていない。

### 13.2 16 Hz（依頼2）

設計は3章のまま（固定の換算、明示的な出力レベル、自動正規化なし）。T の初期値を 0.7 s にしても数値はほぼ同じで、16 Hz 込みは出力レベル 0 dB で LH-60 まで、全セルには −20 dB、そのとき暗騒音 20 dB(A) は −106.6 dBFS。LH-80（16 Hz 込み）のピークと暗騒音 20 dB(A) の実効値の差は約 103 dB で、16 bit には収まらない。

「音量ボタンで後から上げ下げすればよいか」について。アプリ内の出力レベルを下げるのは有効（クリップ前の信号を下げる）。逆に、デジタル出力がクリップした後で端末側の音量を下げても歪みは戻らない。このため上限を超える組み合わせは再生自体をしない。再生できない・小さい・機器が出せない、の区別：(a) 上限超過は斜線セルで再生不可、(b) 再生できるが小さい場合は dBFS を数値で表示し −90 dBFS 未満は「ほぼ無音」と表示、(c) 機器が 16／31.5 Hz を再生できるかは、このページからは判定できない（注意書きのみ）。

### 13.4 表の数値と L_A,Fmax（依頼4）

コードで確認した「数字」の意味と、v2.1.0 での表記。

| 場所 | 意味 | 計算 | 表記 |
|---|---|---|---|
| 表の斜線セル | そのセルを再生できる出力レベル（上限 −1 dBFS から逆算、5 dB 刻み） | 20 log₁₀(上限 ÷ セルのピーク上限) | 「−20」→「**≤−20**」 |
| 表のセル（チェック時） | 衝撃音の参考 L_A,Fmax − 暗騒音のモデル L_Aeq | 下の ① − 列の値 | 「+12」→「**Δ12**」 |
| 指定値モードの行名 | 入力値からの平行移動量 | 5 dB 刻み | 「+5」→「**+5 dB**」 |
| 画面下の出力レベル | 全条件共通のゲイン | — | 「+5 dB」（変更なし） |

衝撃音の作り方と L_A,Fmax：

- 帯域ごとに減衰正弦波の和を作り、**合成後の波形**を帯域フィルタ→F 特性（125 ms）→最大値で分析して、各帯域の L_Fmax が目標に一致するよう帯域ゲインを反復補正している。合わせているのは帯域別 L_Fmax だけ。
- ①「波形から求めた参考 L_A,Fmax」は、その**全帯域の合成波形に A 特性フィルタを掛け、F 特性の時間重み付け後に最大値を取った**値である。帯域ごとに A 補正を足してエネルギー合算したものではない。
- ②「帯域別 L_Fmax ＋ A 補正のエネルギー合算」を別の参考値として併記した。各帯域の最大が同時に起こると仮定した量で、① とは一致しない。実測した1条件（16 Hz 込み、LH-50、T＝0.7 s）では ① 51.4 dB、② 52.3 dB だった。ほかの条件での差は画面の「②−①」で確認できる。
- 帯域別最大値の時刻や波形が変われば ① は変わる。したがって ① は「基準曲線の値」ではなく「この波形の値」であり、画面でもそう書いている。
- ①② とも、出力レベル・暗騒音・連続打撃の重なり・校正を含まない。規格の測定条件を満たす値ではない。
- Δ は最大値（衝撃音）と時間平均（暗騒音）の比較なので、聞こえやすさの目安にとどまる（Δ が 0 でも衝撃音は聞こえる）。Δ の表示は既定でオフ。

各国の規格で全帯域 A 特性最大値と帯域別評価のどちらを使うかは、今回は調べていない（未確認事項）。

### 13.5 再生条件・暗騒音 WAV・再生中の編集（依頼5〜7）

- 連続の打撃間隔 1.9 s（8 打すべて 1.9000 s を波形で確認）、T の初期値 0.7 s（保存済みの値は引き継ぐ）。2 kHz の基準値は 61 dB（LH-65）のまま。
- **暗騒音の WAV**：2 秒以上、先頭 30 秒まで、全チャンネルの平均でモノラル化、再生側のサンプリング周波数へ変換。ループ長は 2 のべき乗サンプル（例：5 s の録音で 2.97 s、3 s の録音で 1.49 s）で、ループ末尾に続く部分を先頭へ最大 0.5 s でクロスフェードする。レベルは、選んだ暗騒音の帯域内の A 特性実効値（モデル L_Aeq）が列の値になるよう全体を一律に増減する。録音の dBFS は使わない。したがって合成ノイズとの比較は「同じモデル L_Aeq で、スペクトルが違う」比較として成立する。実際の音圧は校正がなければ決まらない。帯域内のエネルギーが全体の 0.01 % 未満の録音は、雑音だけを持ち上げることになるので合成ノイズへ戻す。録音は保存しない（開き直すと合成に戻る）。
- **再生中の編集**：基準値・オフセット・指定値・T・暗騒音の傾き／帯域／音源・追加帯域を変えると、入力が止まって 0.5 s 後に再計算し、再生を止めずに引き継ぐ。鳴っている打撃はそのまま鳴り終わり、次の打撃（同じ拍）から新しい音になる。暗騒音が変わる場合は同じ再生位置で 50 ms のクロスフェード。変更後の条件が上限を超える場合は止めて理由を表示する。停止中は鳴らさない。条件モードの切替、衝撃音の音源の切替、校正値の変更は従来どおり停止する。

## 15. v2.1.2：グラフの縮尺

等級曲線・帯域レベルのグラフ3つ（LH、TL の減衰量、TL の帯域レベル）を、すべて **10 dB：1 オクターブ ＝ 20：15**（縦が横の 4/3）の固定縮尺にした。

- 根拠：建築音響の測定報告の図は、1/3 オクターブを 5 mm（1 オクターブ 15 mm）、10 dB を 20 mm とする定め（ISO 140／ISO 10140 系と、それに対応する JIS A 1416 など）という理解による。**この条文は今回、原典でも検索でも確認できていない。**「JIS では縦軸のほうが長い（2：1 程度）」とのご指摘とは、125 Hz〜2 kHz・0〜80 dB の図が約 2：1 の縦長になる点で整合する。比率が違う場合は `src/shell.js` の `CHART.RATIO` の1か所を直せば3つとも変わる。
- LH は帯域を実際のオクターブ位置に置くようにした（16 Hz と 63 Hz だけを選ぶと、31.5 Hz の分が空く）。目盛りは 10 dB 刻み。
- TL の減衰量のグラフは、選んだ帯域だけを描く（従来は常に 16 Hz〜8 kHz の横軸）。
- 実測（`tests/12-chart-scale.mjs`、1280 px と 390 px）：10 dB の高さ ÷ 1 オクターブの幅 ＝ 1.33。作図領域は LH 63〜500 Hz で 187 × 499 px（2.66：1）、TL 125 Hz〜2 kHz で 234 × 562 px（2.40：1）。16 Hz〜8 kHz を選んだ場合（10 オクターブ）は横長になる。

試験は実 Chromium 153（ヘッドレス）で **444／444 項目が合格**。音の処理には変更がない。

3 の待ちは、5 dB ボタンでの通常操作でも「下げてから 0.12 秒以内に再生を押した場合」にだけ入る。

未検証は16章と同じ（実際のマイクと聴取、Safari／Firefox／実機、T 等級線と縮尺の原典照合）。付属試験に合格した版から利用側の検証で不具合が見つかったのは、これで4回目である。今回の試験も、挙げた操作列についての確認にとどまる。

## 18. v2.3.0：低域の立ち上がりと出力レベルの範囲

依頼（2026-11-17）：低域だけが後から膨らむ現象の改善、スピーカーを最大にしても小さいことへの対応、等級間・条件間のレベル関係の維持。v2.2.1 の実装を確認したうえで行った。比較用に v2.2.1 のビルドを `orig/lh-tl-listening-v2.2.1.html` に置いた。

### 18.1 低域（50 Hz 未満）の立ち上がり

**原因の確認**：v2.2.1 は 16／31.5 Hz 帯だけ、4 ms で立ち上がる合成波形をゼロ位相の帯域フィルタ（filtfilt）に通した後、冒頭 200 ms に raised-cosine をかけていた（録音 WAV でも同じ）。全帯域は1つの波形に合成して再生しているので、帯域ごとの再生開始時刻のずれではなく、この 200 ms の窓が低域だけの遅い立ち上がりを作っていた。

**比較した方式**（`study/onset-study.mjs`、結果は `study/out/`）。1帯域だけを LH-50 の目標値に合わせ、包絡（Hilbert）の立ち上がりと、ほかの帯域への漏れ（その帯域で測った L_Fmax と、その帯域の LH-50 目標値との差＝余裕）を調べた。T = 0.5／0.7／2 s。

| 方式（16 Hz 帯、T = 0.7 s） | 包絡 −6 dB 到達 | 25／50／100 ms の包絡 | 隣の帯域への余裕 | 2 オクターブ以上上への余裕 |
|---|---|---|---|---|
| v2.2.1：filtfilt＋冒頭 200 ms | 60.3 ms | −21.4／−9.0／−0.8 dB | 6.4 dB | 38.1 dB |
| 低域処理なし（4 ms の立ち上がりのまま） | 5.3 ms | −0.3／−0.9／−6.0 dB | −4.1 dB | −12.4 dB |
| filtfilt のみ（冒頭の窓なし） | 0 ms（先頭で最大値の 45 % から不連続に始まる） | — | −2.6 dB | −26.4 dB |
| filtfilt＋Hann 1.5 周期（95 ms） | 42.6 ms | −15.0／−3.7／−1.0 dB | **−0.2 dB** | 25.1 dB |
| **採用：Blackman の立ち上がり 2 周期（126 ms）、帯域フィルタなし** | 57.4 ms | −20.6／−8.4／−0.0 dB | 8.2 dB | 30.2 dB |

| 方式（31.5 Hz 帯） | 25／50 ms の包絡 T=0.5 | T=0.7 | T=2 | 隣／2 oct 以上の余裕（最小、T=0.5〜2） |
|---|---|---|---|---|
| v2.2.1 | −20.2／−13.8 dB | −23.3／−16.5 dB | −30.1／−22.5 dB | 9.6／60.7 dB |
| **採用（同上、63 ms）** | −9.8／−6.0 dB | −12.6／−7.9 dB | −17.4／−11.4 dB | 5.1／42.7 dB |

採用した処理：50 Hz 未満の帯域は、合成波形そのものを中心周波数の 2 周期の Blackman 窓の前半で立ち上げ、その後に帯域フィルタをかけない（因果的。打撃より前に音が出ない）。末尾 200 ms のフェードは従来どおりで、冒頭の処理とは分けた。63 Hz 以上の帯域は変更していない（63–500 Hz のみのとき、再生バッファは v2.2.1 とビット単位で一致）。

選んだ理由と限界：
- 短くするほど速く立ち上がるが、16 Hz 帯の漏れが 31.5 Hz 帯の目標値（LH-50 で 18 dB 低い）に届き、16＋31.5 Hz を同時に選ぶと合わせ込みが失敗する。Hann 1.5 周期では実ブラウザで誤差 0.32 dB となり再生不可になった。採用した方式は T = 0.5〜2 s で隣の帯域への余裕が 7.3 dB 以上（v2.2.1 は T = 0.5 s で 2.5 dB）、2 オクターブ以上上への余裕が 29 dB 以上。
- **31.5 Hz 帯は大きく改善した**（25 ms・50 ms の時点で 8〜13 dB 早く立ち上がる）。**16 Hz 帯の改善はわずか**（−6 dB 到達 60 → 57 ms、T = 2 s で 76 → 66 ms）。31.5 Hz 帯との重なりを崩さずに 16 Hz をこれ以上速く立ち上げる方法は、比べた範囲では見つからなかった。
- 1/1 オクターブ帯域に制限した信号は、帯域幅そのもので時間的に広がる。ゼロ位相の 1/1 オクターブ帯域フィルタのインパルス応答は −6 dB までの片側幅が 16 Hz で 54 ms、31.5 Hz で 27 ms、63 Hz で 13.5 ms。採用後の立ち上がりはこの程度で、v2.2.1 の 31.5 Hz（85 ms）はこれを大きく超えていた。
- 解析表示の遅れとの区別：解析用の 36 次の因果的帯域フィルタはピークの遅れが 16 Hz で 406 ms、31.5 Hz で 203 ms あり、時間重み付け F の L_Fmax は打撃後 0.4〜0.8 s で最大になる。これは表示（解析）側の遅れで、再生波形の遅れではない。上の包絡はゼロ位相（遅れなし）で測った。
- 録音 WAV（`extractImpact`）：v2.2.1 は「最大値の 80 ms 前」から切り出し、その先頭 200 ms を低域だけフェードしていたため、打撃そのものを削っていた（試験用の録音で打撃の瞬間 −14.8 dB、25 ms 後も −9.0 dB）。16＋31.5 Hz ではこの録音を合わせ込めず（誤差 2.00 dB、再生不可）。v2.3.0 は最大値の前 0.3 s 以内で最大値の −20 dB に達した点を打撃の始まりとし、低域があるときは切り出しをその 2 周期＋5 ms 前まで広げ、ゼロ位相フィルタが打撃の前に作る低域の前触れだけを Blackman で立ち上げる（窓は打撃の始まりで終わる）。打撃後の 16／31.5 Hz 帯の包絡は、窓をかけずに同じ帯域フィルタに通した録音と 25／50／100 ms で 0.03／0.08 dB 以内、合わせ込み誤差 0.009 dB。打撃の前の余白が足りないとき（目安 0.1 s 未満）は、そのことを表示し、合わせ込めなければ従来どおり再生しない（打撃が先頭 20 ms の録音：誤差 3.53 dB で再生しない。v2.2.1 は 5.45 dB）。
- 200 ms 前にずらす、帯域ごとのピークをそろえる、といった補正はしていない。

- 最も静かな衝撃音（LH-30、63–500 Hz、暗騒音なし）が −1 dBFS に収まる最大の 5 dB 刻みが +60 dB。帯域を足すと上限は下がるだけなので、+60 dB を超える範囲では衝撃音の条件はどれも再生できない。そこで上限を +60 dB とした。
- 初期値 +20 dB：LH-50（63–500 Hz）のピークは −21.9 dBFS（実際の描画で −21.94 dBFS）で、余裕は約 20 dB。このとき再生できる衝撃音は LH-30〜LH-70。LH-80 まで含めて全部を同じゲインで比べるには、63–500 Hz で +5 dB、16 Hz を含めると −25 dB まで下げる必要がある。**「静かな条件を大きく聴く」ことと「最大の条件まで同じゲインで聴く」ことは両立しない**。範囲の説明文にこのことを表示した。
- 16 Hz 帯がデジタルピークを占める：16 Hz を加えると、LH-50 のピークは 16 Hz 帯だけで −11.0 dBFS、それを除くと −42.0 dBFS。上限が約 31 dB 下がる。今回の立ち上がりの変更で 16 Hz 帯のピークは同じ L_Fmax に対し 2.5 dB 上がった（v2.2.1：−13.5 dBFS）。これを範囲の説明文に数値で表示する。小型スピーカーでは 16／31.5 Hz はほとんど再生されないので、この帯域を入れたまま出力レベルを上げても、聞こえる帯域は大きくならない。
- 校正との関係：校正値を初めて入れたとき、出力レベルが正なら 0 dB（＝校正どおり）に下げ、その旨を表示する。+20 dB の初期値のまま校正値を入れると、校正より 20 dB 大きく鳴ってしまうため。下げる方向だけで、後から利用者が変えた値には触れない。
- セルごとのピーク正規化、条件ごとの自動音量調整、コンプレッサー／リミッターは使っていない。条件を切り替えても共通ゲインは変えない。モデル上の帯域レベル、校正値、デジタル出力ゲインは別のまま（表示する等級・目標値は変えていない）。

### 18.3 検証（`tests/15-v230.mjs`、45 項目）

実 Chromium（ヘッドレス）、OfflineAudioContext で実際のエンジンを描画した無音の波形検証。

- 立ち上がり（合成、描画した出力から 1/1 オクターブで抽出）：31.5 Hz 帯は 25／50 ms で v2.2.1 より 9.0／6.1 dB 高い。16 Hz 帯は v2.2.1 より遅くならない（−6 dB 到達 38.4 → 36.3 ms。合成全体から抽出したため、帯域単独の値とは異なる）。63–500 Hz のみでは再生バッファが v2.2.1 と同一。
- 帯域別 L_Fmax：T = 0.5／0.7／1.2／2 s × 5 通りの帯域（63–500、＋31.5、＋16、＋16・31.5、8帯域）で、全帯域が LH-50 の目標値から 0.05 dB 以内。
- 等級差：出力レベルを固定して LH-45／50／55 を描画し、ピーク・実効値とも 5.000 dB 差（63–500 Hz と 16・31.5 Hz 込み）。
- 出力レベル：初期値 +20 dB、表示と上限表示、条件を選んでも出力レベルは変わらない、+60 dB で LH-30 は再生可・LH-35 は上限超過表示、上限超過の条件は再生せず必要な出力レベル（+40 dB）を表示、−40 dB 下限。
- 上限の確認：単発・3回・連続 × {LH-50、LH-50＋暗騒音30、LH-80＋暗騒音70、暗騒音70のみ、LH-30} を、それぞれの条件で設定できる最大の出力レベルで描画し、すべて −1 dBFS 以下・計算上の上限以下・NaN なし。+40 dB で連続打撃中に6条件（うち1つは上限超過）を切り替えてもピーク −2.06 dBFS。
- 増幅中の変化：暗騒音 20 dB(A) を再生しながら「＋」を 8 回（+20 → +60 dB）。同じ暗騒音を変化なしで描画したものとの比からゲインの時間変化を求め、最後に +40.00 dB、サンプル間の最大の変化 0.018 dB、一度も下がらない（段差・クリック相当の跳びなし）。停止・条件切替時のピークは既存の試験（09〜14）で確認済みで、今回も全て合格。

### 18.4 残る制約と未検証

- **耳元の音圧は測っていない**。ここでの数値はすべてデジタル出力（dBFS）の計算値と描画値である。実際の音圧は再生機器の音量設定とスピーカーで決まり、未校正では「モデル上の 126 − 出力レベル dB が 0 dBFS」という対応しかない。
- 16 Hz 帯の立ち上がりは、31.5 Hz 帯の合わせ込みを保つ範囲ではほとんど速くできなかった。
- 16 Hz を入れると出力レベルの上限が約 30 dB 下がる。スピーカーで聴くときは 16／31.5 Hz を外す方が、聞こえる帯域を大きくできる（画面にも表示）。
- v2.2.1 で保存した出力レベルはそのまま開く。0 dB のままなら、「＋」で上げる必要がある。
- 実際の試聴（どのスピーカーでどう聞こえるか）、Safari／Firefox／実機は未確認。立ち上がりの改善が聴感上どの程度かは、聴いて確かめる必要がある。
