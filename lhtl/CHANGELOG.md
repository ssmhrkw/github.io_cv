## 2.1.1（2026-11-15）

### 追加

### 変更
- TL：条件の切替を、旧音と新音の開始・終了を揃えた 10 ms の相補クロスフェード（二乗余弦）に。原音への 1.5 秒ランプを廃止（再生開始時のみ原音は 0.2 秒で立ち上げ）。選択中の条件の再押下は無変化。全ボイスをサンプル境界に整列。
- LH：連続の打撃間隔 1.8 → 1.9 s。減衰時間 T の初期値 0.5 → 0.7 s（保存済みの値はそのまま）。
- LH：セル切替時、同じ暗騒音は鳴らしたままレベルだけ 50 ms で動かす（無音の隙間をなくした）。連続再生中の同じセルの再押下は無変化。
- LH：再生中に基準値・オフセット・指定値・T・暗騒音の傾き／帯域・追加帯域を変えると、止めずに新しい音へ引き継ぐ。停止中は鳴らさない。

- LH：グラフに等級曲線 LH-70〜LH-30 を並べ、選択中を強調。目標値（◇）と生成波形の分析値（●）、オフセット、参考外挿（破線）を区別。

### 修正（WIP-1 に対する報告3件）
- LH：停止やセル切替の直後に出力レベルを上げると、フェード中の旧音源まで増幅された。上げは旧音源が消えるまで待って適用する。
- TL：切替を直列に予約していたため、切替が重なると停止が遅れた（最大約 1.3 s）。入れ子のクロスフェードにして予約をなくし、停止は即時（23 ms）にした。
- TL：「低下量」と帯域レベルを、切り出し・フェード前のスペクトルから計算していたため、短い音で実際の再生波形と合わなかった。実際に鳴らすバッファから計算する。



### 修正（v2.0.0 納品後の報告5件）
- LH：帯域分析を信号の末尾で打ち切っていたため、短い録音＋16 Hz で帯域レベルが目標より大幅に高くなり、誤差表示も過小だった。分析に信号後の無音（フィルタ応答の末尾）を含めた。最低帯域の 8 周期に満たない録音は理由つきで拒否。
- LH：WAV の読み込みに失敗すると、指定値の条件が保存上だけ「等級」に変わり、表示と食い違った。成功するまで何も変更しない。
- LH：WAV 読み込み中に条件を変えると、読み込み完了が後の選択を上書きした。後の選択を優先し、録音は選択可能な状態で残す。
- TL／LH：NaN・∞ を含む WAV を拒否。ピーク計算は非有限値で ∞ を返す。TL は新しい音源の処理に失敗したら元の音源へ戻す。
- TL：処理が一度失敗すると再生を押しても復旧しなかった。LH も計算失敗後の再生で再計算する。

## 2.0.0（2026-11-15）

LH（`lh-listening` v4 系）と TL（`tl-listening` v1）を共通のソースに作り直した。

### 追加
- LH／TL をタブで切り替える1ファイル版 `lh-tl-listening.html`。単体版 `lh-listening.html`、`tl-listening.html` も同じソースから生成。
- LH：帯域追加チェック4種（16／31.5 Hz、1／2 kHz）。衝撃音と暗騒音の帯域を別々に表示。暗騒音の帯域選択（広帯域／63〜500 Hz）。
- LH：全条件共通の「出力レベル」（−40〜+20 dB、5 dB 刻み）。再生できないセルの表示と、必要な出力レベルの提示。
- LH：デジタル出力（dBFS）の表示。暗騒音が −90 dBFS を下回るときの数値つき警告。
- TL：原音からの低下量（Z／A 特性）の表、原音へのランプ、原音パッド、室条件換算、基準曲線の値を写すボタン。
- 画面下に固定した再生バー（状態、再生中の条件、音量、再生、停止）。Esc で停止。表の矢印キー操作。
- 起動エラーを画面に表示（要素名つき）。

### 変更
- LH：未校正の換算を K = 126 dB 固定に。セル・帯域による共通減衰の自動変更を廃止。上限 −6 → −1 dBFS。重なりは実波形で計算。
- LH：追加帯域の基準値を round(62 − A(f))（LH-65）に統一。16 Hz：119、31.5 Hz：101、1 kHz：62、2 kHz：61 dB。
- LH：連続の打撃間隔 1.5 → 1.8 s。合成音の乱数の種を帯域ごとに固定。
- LH：表を横スクロールなしに。セルの数値表示は既定オフ。L_A,Fmax は折りたたみ内へ。
- TL：既定の帯域を 125 Hz〜2 kHz（外挿なし）に。計算周波数を正確なオクターブ刻みに。帯域マスクの形を変更。
- TL：条件変更で自動再計算し、再生中なら再開。モード切替で入力値を上書きしない。音量は 5 dB 刻み（既定 −10 dB）。
- 数値入力：有効値は即保存、無効値は保存せず理由を表示し、フォーカスが外れたら元に戻す。
- 配色：Light／Dark／Black を維持し、Nippon Colors の値でコントラストを確保（白群 #78C2C4、藍墨茶 #373C38 を追加使用）。

### 削除
- LH：出力方式「試聴：選択セルごとにゲイン調整」。「暗騒音だけを再生」の選択欄と「指定値で再生」ボタン（機能は表に統合）。
- TL：「曲線を適用」ボタン（自動適用）。
- Google Fonts の外部読み込み。

### 修正
- 16 Hz を含めると全体が約 40 dB 小さくなり、暗騒音が聞こえなくなる問題。
- TL：再生中に複数の欄を続けて変更すると再開されない問題（今回の試験で検出）。
- TL：最低帯域の下半分がフェードにかかり、範囲外の外挿値へ補間していた点。

### 保存設定
- 新しいキー：`lh-listening-v5`、`tl-listening-v2`、`listening-shell-v1`。
- 旧キー（`lh-listening-v1`〜`v4-range`、`tl-listening-v1`）は読み取って移行し、削除しない。
  - LH の帯域範囲：従来範囲 → 1 kHz、拡張 → 31.5 Hz＋1 kHz、広帯域 → 16＋31.5 Hz＋1 kHz、指定値 → 指定値の条件（暗騒音 63〜500 Hz）。
  - 等級曲線の編集値、オフセット、校正値、T、傾き、打撃パターン、配色、TL の条件・等級・帯域・入力値を引き継ぐ。
  - `outputMode` は引き継がない。出力レベルは 0 dB から始まる。
