LH等級の聴き比べ

重量床衝撃音の等級（LH-30〜LH-80）と暗騒音（20〜50 dB(A)）の組み合わせを、セルをタップして再生します。衝撃音は各帯域の Li,Fmax が等級曲線にちょうど接するように合成しています。

未校正（相対比較）

再生環境：63 Hz 帯は iPad の内蔵スピーカーからはほとんど出ません。外部スピーカーかヘッドホンを使ってください。LH-70 以上は大きな音になるので、最初は音量を下げて試してください。

セルの数値は ΔLA = LA,Fmax（衝撃音）− LAeq（暗騒音）。色が濃いほど衝撃音が暗騒音を上回ります。「なし」列は LA,Fmax。⚠ は出力が 0 dBFS を超える組み合わせ（この端末と音量では正しく再生できません）。

校正
  1. 受聴位置に騒音計を置きます（ヘッドホンの場合はカプラなど）。
  2. 端末の音量を決めます。校正後は音量を変えないでください。
  3. 帯域の「再生」で −20 dBFS のオクターブバンドノイズが流れます。Z 特性・1/1 オクターブの Leq（10 s 以上）を測って入力します。

1 kHz だけ入れても使えます（全帯域を同じ値とみなします）。未入力の帯域は入力済みの帯域から補間し、外側は端の値を使います。入力値はこのブラウザに保存されます。

計算方法

等級曲線：JIS A 1419-2:2000 の重量床衝撃音の等級曲線。L-50 を 63/125/250/500 Hz で 73/63/56/50 dB とし、等級 G の目標値は Lb(G) = Lb(50) + (G − 50) + オフセットb。1 kHz・2 kHz は評価外の帯域で、500 Hz 基準値からの差（初期値 −10 dB・−20 dB）は仮定です。

衝撃音（合成）：帯域 b ごとに Nb 本（8/12/20/30/40/40 本）の減衰正弦波を足し合わせます。周波数は帯域内にランダム（乱数の種は固定）。全等級で同じ波形を使い、等級による違いはレベルだけです。

pb(t) = Σk ak (1 − e−t/τa) e−6.91 t/T sin(2π fk t + φk)、τa = 4 ms

帯域レベルの合わせ込み：足し合わせた音を 1/1 オクターブ（Butterworth の HP 36 次 × LP 36 次、wav2Fmax と同じフィルタ。帯域端は IEC 61260-1:2014 の基数 10）で分析し、F 特性（τ = 0.125 s、IEC 61672-1:2013）の最大値 LFmax が目標値に一致するまで帯域ゲインを反復補正します。LA,Fmax は A 特性フィルタ（IEC 61672-1:2013 附属書 E の極・零点を双一次変換）を通した F 特性最大値です。

暗騒音：振幅スペクトルにランダム位相を与えて逆 FFT（219 点前後、約 11 s）。周期信号なので継ぎ目なくループします。LAeq は周波数領域で A 特性の重みを掛けて合わせています。

校正：帯域 b で −20 dBFS のノイズを測った値を Mb とすると Kb = Mb + 20（0 dBFS に相当する音圧レベル）。目標 L の帯域成分は 10(L − Kb)/20 の振幅で出力します。未校正のときは Kb = 118 dB とします。

⚠ の判定：衝撃音のピークと暗騒音のピークの和（安全側）が 0 dBFS 以上。

注意：全帯域が曲線に接するので、同じ等級の実際の床より LA は大きめになります。実際の床に近づけるには、接しない帯域にオフセットを入れてください。ΔLA は目安で、聞こえるかどうかは帯域ごとの差（表）で考えるほうが確かです。
